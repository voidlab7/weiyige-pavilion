```
检查 ai-workspace/ 下是否存在 state.json：

路径 A — 断点续做（state.json 存在 + 有 completed 阶段 + 有 pending 阶段）：
  → 展示恢复摘要：已完成阶段/剩余阶段/当前位置
  → 直接从 current_phase 继续

路径 B — 重新开始（用户明确说"重新开始"/"从头"/"重新分析"）：
  → 备份 state.json → state.json.bak.{timestamp}
  → 重置所有阶段状态为 pending
  → 从头开始

路径 C — 首次执行（state.json 不存在或 task_id 不匹配）：
  → 初始化工作区 + state.json
  → 正常走流程
```
