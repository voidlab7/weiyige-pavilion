# 路线图

> 维弈阁的未来方向。

---

## 近期（进行中/已排期）

- **架构优化 11 项**：见 [优化总计划](../architecture-optimization/index.html)
  - P0: CLI 全覆盖 state 写操作 + 状态校验 hook + finish-task 强制检查
  - P1: IDENTITY 精简 + 分级加载 + 共享知识外置
  - P2: 自动 git commit + 状态变更历史 + 快照回退
  - P3: CLI 环境自适应 + hook 平台分支

## 中期

- **多项目并行调度**：ops 调度器支持跨项目任务分发
- **记忆系统升级**：教训自动升级为可执行规则的闭环
- **角色技能热加载**：运行时动态注册新 Skill，不需重启
- **审查质量度量**：Layer 1 评分数据聚合，发现审查偏差

## 远期

- **开源社区**：支持用户自定义角色 + Skill 贡献
- **可视化编排**：拖拽式任务链路编辑器
- **跨团队协作**：多个维弈阁实例间的任务委托
