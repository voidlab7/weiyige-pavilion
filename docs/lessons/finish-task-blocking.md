# finish-task 阻塞

> 过度防御导致人为阻塞点。

---

## 现象

`finish-task` 检测到 `running/` 目录有残留文件 → 拒绝完成 → 需要人点 "Run" 批准 `rm` 命令 → 人不在就卡死。

## 根因

running/ 残留被当作异常拦截，但 running/*.lock 是 `init-task` 自己创建的，`finish-task` 完全有权清理。

## 修复

移除 running/ 残留检查，由 `finish-task` 内部的 `cleanRunning()` 自动清理。

前置检查只拦**真正需要人决策的问题**（如阶段未完成），自己能解决的事不拦。

## 教训

CLI 的前置检查应该区分：
- **需要人决策** → 拦（如阶段未完成）
- **自己能解决** → 自动处理（如清理自己创建的文件）

过度防御 = 制造人为阻塞点。
