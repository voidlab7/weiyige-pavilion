术语表

维弈阁核心概念速查。按分类排列。

角色

术语含义
锋·CEO方向决策者，最终审批权。@锋 @ceo
砺·合伙人质疑挑战者，魔鬼代言人，YC Office Hours。@砺 @devil
隐·顾问多角度深度分析，独立二评。@隐 @advisor
枢·PM需求定义、PRD、进度管理。@枢 @pm
辞·内容内容创作、文案润色、去 AI 味。@辞 @content
寻·探索热点趋势、竞品调研、信息搜索。@寻 @scout
矩·架构技术架构、工程审查、代码质量。@矩 @arch
铸·开发代码实现、左移检查、Bug 修复。@铸 @dev
绘·设计UI/UX 设计、设计审查、设计系统。@绘 @design
鉴·QA功能测试、Bug 修复、回归验证。@鉴 @qa
盾·安全安全审计、威胁建模、OWASP。@盾 @sec
算·财务成本分析、预算管理、ROI。@算 @cfo
启·执事自动编排器，不干活只调度。@启 @auto @team

层级

术语含义
战略层锋 + 砺 + 隐。方向决策、质疑、深度分析
执行层枢 + 辞 + 寻。需求拆解、内容创作、信息探索
质量层矩 + 绘 + 铸 + 鉴 + 盾。设计、开发、测试、安全
运营层算。成本追踪、预算管理

协议与机制

术语含义
RACI 矩阵职责分配：R(负责) A(审批) C(咨询) I(知会)
交接块 (Handoff Block)Agent 完成工作后输出的结构化信息，含来源/状态/产物/下游建议
门禁 (Gate)阶段退出时的质量检查关卡，gate-01 到 gate-06
两层门禁Layer 0（确定性检查，0 token）+ Layer 1（AI 语义审查）
Layer 0确定性检查：文件存在性、lint、格式验证。不通过直接打回
Layer 1AI 语义审查：调用 artifact-review Skill 多维度评分
左移检查 (Shift-Left)代码生成后立即跑 Lint/类型检查，不等测试阶段

加载

术语含义
L0身份卡片层：IDENTITY.md（< 500 token），角色激活时自动加载
L1方法论层：SOUL.md（1000-5000 token），Deep/Team 模式自动加载
L2领域知识层：memory/*.md + skills/，特定场景按需加载
Quick 模式仅 L0，2-5 分钟快速回答
Standard 模式L0，需要时升级 L1（默认）
Deep 模式L0 + L1，完整深度执行
Team 模式启编排多角色串联，L0 + L1

角色文件

术语含义
IDENTITY.md角色身份卡片：名称、风格、核心指令（< 500 token）
SOUL.md角色方法论：思维框架、决策逻辑、完整工作流
SKILLS.md角色技能卡片清单：触发条件/输入/输出/约束
memory/角色记忆目录：教训、知识、偏好（各项目独立）

CLI

术语含义
weiyige-cli维弈阁确定性操作工具包，强制状态管理
init-task创建任务：state.json + running/ lock + ops 同步
update-phase更新阶段：依赖检查 + 状态写入 + ops 同步
handoff原子交接：产物验证 + JSONL 日志 + 状态推进
gateLayer 0 门禁检查：前置阶段 + 产物 + 格式
finish-task完成任务：前置检查 + 清理 + ops 同步
state.json任务状态文件（CLI 管理，禁止手动写）
project-status.json项目状态文件（CLI 自动同步，ops dashboard 读取）
handoff-log.jsonl交接日志（追加写入，可追溯）

运维

术语含义
weiyige-ops运维工具仓库：CLI + Dashboard + 调度器
weiyige-pavilion协议仓库：角色定义 + 协议 + 技能 + 门禁
health-checker文件系统监控，读取 state.json 渲染 Dashboard
sync-weiyige.sh同步脚本，从 pavilion 根目录同步到所有注册项目
registry.json项目注册中心，记录所有使用维弈阁的项目路径
running/运行中任务的 lock 文件目录
queue/待执行任务队列
done/已完成任务归档

阶段

术语含义
01-ideation构思：方向确认，锋 + 砺 + 隐
02-requirement需求：PRD 定义，枢
03-design设计：架构 + UI，矩 + 绘
04-development开发：代码实现，铸
05-testing测试：QA + 安全，鉴 + 盾
06-summary总结：汇总归档，启
