# 术语表

## 角色

| 术语 | 含义 |
|------|------|
| **锋·CEO** | 方向决策者，最终审批权。`@锋` `@ceo` |
| **砺·合伙人** | 质疑挑战者，魔鬼代言人，YC Office Hours。`@砺` `@devil` |
| **隐·顾问** | 多角度深度分析，独立二评。`@隐` `@advisor` |
| **枢·PM** | 需求定义、PRD、进度管理。`@枢` `@pm` |
| **辞·内容** | 内容创作、文案润色、去 AI 味。`@辞` `@content` |
| **寻·探索** | 热点趋势、竞品调研、信息搜索。`@寻` `@scout` |
| **矩·架构** | 技术架构、工程审查、代码质量。`@矩` `@arch` |
| **铸·开发** | 代码实现、左移检查、Bug 修复。`@铸` `@dev` |
| **绘·设计** | UI/UX 设计、设计审查、设计系统。`@绘` `@design` |
| **鉴·QA** | 功能测试、Bug 修复、回归验证。`@鉴` `@qa` |
| **盾·安全** | 安全审计、威胁建模、OWASP。`@盾` `@sec` |
| **算·财务** | 成本分析、预算管理、ROI。`@算` `@cfo` |
| **启·执事** | 自动编排器，不干活只调度。`@启` `@auto` `@team` |

## 层级

| 术语 | 含义 |
|------|------|
| **战略层** | 锋 + 砺 + 隐。方向决策、质疑、深度分析 |
| **执行层** | 枢 + 辞 + 寻。需求拆解、内容创作、信息探索 |
| **质量层** | 矩 + 绘 + 铸 + 鉴 + 盾。设计、开发、测试、安全 |
| **运营层** | 算。成本追踪、预算管理 |

## 协议与机制

| 术语 | 含义 |
|------|------|
| **RACI 矩阵** | 职责分配：R(负责) A(审批) C(咨询) I(知会) |
| **交接块 (Handoff Block)** | Agent 完成工作后输出的结构化信息，含来源/状态/产物/下游建议 |
| **门禁 (Gate)** | 阶段退出时的质量检查关卡，gate-01 到 gate-06 |
| **两层门禁** | Layer 0（确定性检查，0 token）+ Layer 1（AI 语义审查） |
| **Layer 0** | 确定性检查：文件存在性、lint、格式验证。不通过直接打回 |
| **Layer 1** | AI 语义审查：调用 artifact-review Skill 多维度评分 |
| **左移检查 (Shift-Left)** | 代码生成后立即跑 Lint/类型检查，不等测试阶段 |

## 加载

| 术语 | 含义 |
|------|------|
| **L0** | 身份卡片层：`IDENTITY.md`（< 500 token），角色激活时自动加载 |
| **L1** | 方法论层：`SOUL.md`（1000-5000 token），Deep/Team 模式自动加载 |
| **L2** | 领域知识层：`memory/*.md` + `skills/`，特定场景按需加载 |
| **Quick 模式** | 仅 L0，2-5 分钟快速回答 |
| **Standard 模式** | L0，需要时升级 L1（默认） |
| **Deep 模式** | L0 + L1，完整深度执行 |
| **Team 模式** | 启编排多角色串联，L0 + L1 |

## 角色文件

| 术语 | 含义 |
|------|------|
| **IDENTITY.md** | 角色身份卡片：名称、风格、核心指令（< 500 token） |
| **SOUL.md** | 角色方法论：思维框架、决策逻辑、完整工作流 |
| **SKILLS.md** | 角色技能卡片清单：触发条件/输入/输出/约束 |
| **memory/** | 角色记忆目录：教训、知识、偏好（各项目独立） |

## CLI

| 术语 | 含义 |
|------|------|
| **weiyige-cli** | 维弈阁确定性操作工具包，强制状态管理 |
| **init-task** | 创建任务：state.json + running/ lock + ops 同步 |
| **update-phase** | 更新阶段：依赖检查 + 状态写入 + ops 同步 |
| **handoff** | 原子交接：产物验证 + JSONL 日志 + 状态推进 |
| **gate** | Layer 0 门禁检查：前置阶段 + 产物 + 格式 |
| **finish-task** | 完成任务：前置检查 + 清理 + ops 同步 |
| **state.json** | 任务状态文件（CLI 管理，禁止手动写） |
| **project-status.json** | 项目状态文件（CLI 自动同步，ops dashboard 读取） |
| **handoff-log.jsonl** | 交接日志（追加写入，可追溯） |

## 运维

| 术语 | 含义 |
|------|------|
| **weiyige-ops** | 运维工具仓库：CLI + Dashboard + 调度器 |
| **weiyige-pavilion** | 协议仓库：角色定义 + 协议 + 技能 + 门禁 |
| **health-checker** | 文件系统监控，读取 state.json 渲染 Dashboard |
| **sync-weiyige.sh** | 同步脚本，从 pavilion 根目录同步到所有注册项目 |
| **registry.json** | 项目注册中心，记录所有使用维弈阁的项目路径 |
| **running/** | 运行中任务的 lock 文件目录 |
| **queue/** | 待执行任务队列 |
| **done/** | 已完成任务归档 |
